# moffin

Minimalist pink user dashboard and authentication system built with Next.js 16 and connected to a NestJS MySQL backend.

## Features
- **Minimalist Pink UI**: Aesthetic pastel pink theme with soft cards and subtle glows
- **Live User Listing**: Fetches registered users directly from MySQL database
- **JWT Authentication**: Login and registration with access tokens and refresh tokens
- **Connected Backend**: Works with Postman and MySQL Workbench

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
